# Kalkulator Ketebalan Dinding Pipa

Kalkulator wall thickness pipa baja (ASME B31.8 / ASME B31.3) sebagai web app.
Buka `index.html` lewat GitHub Pages, lalu di iPhone: Safari → Share → Add to Home Screen.

Saat memperbarui `index.html`, ubah juga `VERSION` di `sw.js` (mis. `wt-v2`) supaya cache offline ikut diperbarui.
